macOS hides files that start with a dot, so .env may not appear in Finder by default.

Option A:
1. Drag RENAME_TO_DOT_ENV.txt into the root of your repo.
2. Rename it exactly to: .env

Option B:
1. Press Command + Shift + Period in Finder to show hidden files.
2. Drag the included .env file into the root of your repo.

Do not commit .env to GitHub.
